=== STAC extensions

`item.stac_extensions` is derived purely from which properties/assets ended up
populated (`response/stac_extensions.py`), not from a dedicated ODE field:

* Always declared: `ssys` and the PDSSP schema (`pdssp_schema`).
* Declared when at least one property (on the item or on any asset) has a key
  starting with the given prefix: `product` → `product` extension,
  `sat` → `sat` extension, `view` → `view` extension, `file` → `file`
  extension, `proj` → `projection` extension, `processing` → `processing`
  extension.
* Declared when the exact key is present on the item properties: `version` →
  `version` extension, `published` → `timestamps` extension.

`collection.stac_extensions` is a fixed list set at collection-build time
(`ssys`, `scientific`, `processing`, `product`), independent of which fields
are actually populated for a given collection.

=== NASA ODE

This section details the mapping between the **indexterm:[O&M]<<acr-om,O&M>> (Observations & Measurements)** standard interfaces and the **NASA indexterm:[ODE]<<acr-ode,ODE>> (Orbital Data Explorer)** model classes.
Each <<acr-ode,ODE>> class is presented as an extension of the <<acr-om,O&M>> interfaces, with <<acr-ode,ODE>>-specific attributes and associations tailored to NASA's planetary data context.


==== ODEHost

The **ODEHost** class implements the **<<acr-om,O&M>> Host** interface to include <<acr-ode,ODE>>-specific attributes for describing the platform (e.g., spacecraft, observatory) carrying the instrument.

.ODEHost Class Diagram
[plantuml,ode-host-class-diagram]
